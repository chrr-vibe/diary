# Diary

날씨 도트와 함께 쓰는 월별 일기장이에요. 26.10부터 27.3까지 달마다 탭이 있고, 별을 누르면 캐릭터가 랜덤 일기 하나를 읽어줘요.

## 파일

| 파일 | 역할 |
| --- | --- |
| `index.html` | 앱 전체 (폰트, 캐릭터 이미지, 도트까지 모두 들어 있음) |
| `manifest.webmanifest` | 홈 화면에 앱으로 설치할 때 쓰는 정보 |
| `sw.js` | 오프라인에서도 열리게 하는 서비스 워커 |
| `favicon.png` | 브라우저 탭 아이콘 |
| `apple-touch-icon.png` | 아이폰 홈 화면 아이콘 |
| `icon-192.png`, `icon-512.png` | 안드로이드 홈 화면 아이콘 |
| `icon-maskable-512.png` | 안드로이드 둥근/모양 아이콘용 |
| `.nojekyll` | GitHub Pages가 파일을 그대로 올리게 하는 빈 파일 |

## GitHub Pages에 올리기

1. 새 저장소를 만들고 이 폴더 안의 파일을 전부 최상위에 올려요. `.nojekyll`도 꼭 같이 올려요.
2. 저장소의 **Settings → Pages**에서 Source를 `Deploy from a branch`, 브랜치를 `main` / `/ (root)`로 정하고 저장해요.
3. 1–2분 뒤 `https://아이디.github.io/저장소이름/` 주소로 열려요.
4. 폰에서 열고 브라우저 메뉴의 **홈 화면에 추가**를 누르면 앱처럼 쓸 수 있어요.

## 수정본을 올릴 때

`index.html`을 바꿨다면 `sw.js` 맨 위의 `VERSION` 값을 `diary-v2`, `diary-v3`처럼 하나씩 올려 주세요. 그래야 이미 설치한 폰에서도 새 버전으로 바뀌어요.

## 데이터

- 일기는 그 기기의 브라우저 안에만 저장돼요. 서버로 보내지 않아요.
- 브라우저 데이터를 지우거나 다른 기기로 옮길 때는 샴페인 버튼 → **Save backup file**로 백업하고, 새 기기에서 **Restore from file**로 불러와요.
- 달을 더 늘리려면 `index.html`에서 `N_MONTHS = 6` 숫자를 바꾸면 돼요.
